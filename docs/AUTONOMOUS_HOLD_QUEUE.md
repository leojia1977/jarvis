- HOLD entries remain blocked until the named unblocking input is governed.
- AI may prepare only the listed safe drafting work.
- Any ambiguity keeps the item in HOLD.
- No HOLD queue item authorizes real access, credentials, launch execution, public endpoint work, or parked-stream reopen.
- `ACTIVE` policy does not create blanket Red execution and does not close AHQ-003 through AHQ-014 or AHQ-017.
- Autonomous operation startup does not close any HOLD item by itself.
- AHQ-020 allows only the verified Claude Code review-only verdict-line path in `docs\CC_SWITCH_REVIEW_ONLY_INVOCATION_RUNBOOK.md`; it still blocks Claude Code file edits, command execution, staging, commit, push, Red execution, secret handling, strict JSON-schema reliance, non-bare invocation, command-argument multi-line prompt use, and use as sole final reviewer for cc-switch verification stages.
- AHQ-020 reviewer limitation: Claude Code output produced through this path is review evidence only and cannot be the sole independent final reviewer when Claude Code behavior, cc-switch routing, or this invocation path is itself under verification; use Claude Web through the verified AdsPower path or human-supervised external review for those stages.
- AHQ-021 allows only safe Claude Web review-prompt transfer through the governed AdsPower path.
- AHQ-022 allows only the configured AdsPower profile launch/attach path to Claude Web review-prompt readiness; it still blocks profile switching, profile creation, login automation, cookie/session/token/auth-header inspection, browser storage/profile-file inspection, and broader session control.
- AHQ-024 allows only install/help visibility and WSL/PTTY provisioning evidence for `mini-swe-agent`; it blocks main agent execution, implementation assistance, tests, dependency changes, staging, commit, push, route selection, review replacement, closeout ownership, and Yellow backlog participation until a normal user-controlled WSL2 distro or governed PTY runner is provisioned and a separate no-write dry-run verification route passes.
