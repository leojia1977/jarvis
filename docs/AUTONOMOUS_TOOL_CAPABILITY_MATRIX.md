## 3. Current Maturity Summary

Current claimed maturity is L3 limited for AdsPower / Claude Web review-prompt round trip and configured profile launch/attach to review-prompt readiness. Claude Code through cc-switch routed `claude.cmd` is L2 review-only with limits for stdin prompt transfer and first-line verdict capture. Codex and Codex CLI remain L1. VS Code remains L1 as a governed workspace/editing surface only, with no independent review, approval, route, manifest PASS, or closeout authority. SWE agent is L0 / HOLD because it is not installed or discoverable. L4 and L5 are not claimed by this stage.

No credentials, tokens, cookies, auth headers, session data, or account material may be entered into repo, chat, prompts, review packs, or logs.

The cc switch command-path provisioning stage raises only Claude Code review-only verdict capture to L2 with limits. AHQ-020 is no longer a blocker for bounded Claude Code review-only evidence, but it still blocks Claude Code edits, command execution, staging, commit, push, Red execution, secret handling, strict JSON-schema reliance, non-bare invocation, command-argument multi-line prompt use, and use as sole final reviewer for cc-switch verification stages. AHQ-021 remains review-prompt-only for Claude Web, and AHQ-022 remains limited to configured profile launch/attach without profile switching, login automation, or session inspection. This stage does not authorize Red execution or full autonomous implementation.

The SWE agent capability verification stage does not unlock SWE agent. AHQ-024 blocks SWE agent installation, execution, implementation assistance, review replacement, manifest/gate/release ownership, staging, commit, push, and Yellow backlog participation until a separate governed install and capability verification route passes.
