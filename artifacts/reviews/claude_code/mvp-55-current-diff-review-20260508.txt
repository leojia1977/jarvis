### Findings

**P2 — No zip-level manifest integrity test**

`package_manifest.json` is written to disk and included in the zip via `create_zip()`, but is not listed in its own `package_files`. An external consistency validator iterating `package_files` will count 13 files but find 14 in the zip.

- File: `scripts/build_local_offline_trial_rc.py:529–542`
- The return dict exposes `file_count: len(entries) + 1` (line 552) which accounts for this, but the manifest on disk has no corresponding field.
- Fix: Add a test that opens the zip, confirms `package_manifest.json` is present, and confirms `manifest_self_sha256` verifies. Alternatively, add `"manifest_file": "package_manifest.json"` to the written manifest so a validator knows the +1 is intentional.

**P3 — No tampering/mutation test**

No test verifies that modifying any manifest field causes hash verification to fail.

- File: `backend/tests/test_build_local_offline_trial_rc.py`
- Fix: Add a test case that reads the manifest, mutates one field (e.g. `candidate`), and asserts `builder.manifest_self_sha256(mutated) != original_hash`.

