### INFO — `closed_item_count` carries dual semantics across schemas

- `reviewer_backlog.json` root: `"closed_item_count": 2` — aggregate count of all closed items in the backlog (001 + 002).
- `reviewer_backlog_closeout.json`: `"closed_item_count": 1` — count of items closed by this specific script invocation.
- `reviewer_backlog.md` header: `closed_item_count = 2` (backlog-level).

Both values are individually correct, but the same field name means different things in different schema contexts. Any tooling that reads `closed_item_count` from both files and compares them would get a false mismatch. No immediate action needed, but worth noting in the schema docs.
