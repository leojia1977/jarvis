**Findings ordered by severity:**

---

**[MEDIUM] Absolute local machine paths baked into committed artifact**

`artifacts/local_demo_packages/.../package_manifest.json` lines 577–638 contain `D:/产品设计/New folder/...` as hardcoded `source_artifact_dir`, `package_dir`, and `path` values for every entry. These were generated by `scripts/package_s1_local_demo.py:1009-1010` using `artifact_dir.as_posix()` (resolved absolute). Any consumer on a different machine gets invalid paths. The artifact should either use repo-relative paths or be excluded from source control (generated at demo time).

---

**[LOW] Forbidden key scanner uses exact-name match only — partial variants pass**

`scripts/package_s1_local_demo.py:937` extracts leaf keys and compares lowercase to `FORBIDDEN_LEAF_KEYS`. Keys like `auth_token`, `raw_payload_v2`, `secret_key`, or `bearer_token` would not match. Given this is a synthetic/MVP safety gate, acceptable risk, but the gap should be documented.

---

**[LOW] No recursion depth limit in `flatten_json`**

`package_s1_local_demo.py:898-910` — unbounded recursion. Pathologically nested JSON (intentional or corrupted) causes `RecursionError` rather than a clean `HOLD`. Low risk for controlled fixture input.

---

**[LOW] Test gap: `contains_raw_payload: true` branch not exercised**

`test_package_s1_local_demo.py` tests missing-file and forbidden-key HOLD paths but has no test for the manifest-flag check (`artifact_manifest.json` artifacts entry with `contains_raw_payload: true`). That path is implemented in `validate_artifact_dir:954-955` but untested.

---

**[INFO] `start_time_utc == end_time_utc` in `run_record.json`**

Both are `2026-04-30T11:37:45Z`. Zero-duration run is a fixture placeholder. Not a safety issue, but a traceability gap if this record is used for audit purposes.

---

**[INFO] `main()` → `run()` indirection is dead weight**

`package_s1_local_demo.py:1043-1044` — `main()` does nothing but call `run()`. One of them should be removed.

---
