# Incoming Materials

This directory is for external input only.

Examples:
- zip files from other folders
- Claude-generated drafts
- old release bundles
- files shared over chat or copied from another workspace

## Rules
1. Do not run code from this directory as the latest truth.
2. Do not package releases from this directory.
3. Do not point Claude or Codex to this directory as the active codebase.
4. Import required files into `D:\产品设计\New folder` first, then update the manifest.
